# Instructions:

## Run this at the terminal
```
git clone https://github.com/crome1394/hyprland-installer
cd hyprland-installer
chmod +x setdep.sh
```
## Start the GUI
```
sudo systemctl enable --now sddm.service
```

## Run the installer to setup hyprland and install my applications
```
chmod +x install.sh
./install.sh
```
